# Drag and Drop List 🖱️

A simple and interactive drag-and-drop list project built using HTML, CSS, and JavaScript.

Users can drag list items from one container and drop them into another container using the native HTML5 Drag and Drop API.

## 🚀 Features

- 🖱️ Drag and drop list items
- ↔️ Move items between containers
- ⚡ Smooth and interactive user experience
- 🎨 Modern dark-themed UI
- 📱 Responsive layout
- 💻 Built with vanilla JavaScript
- 🚫 No external libraries or frameworks

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Drag and Drop API

## 🎯 Purpose

- This project was created to practice:
- DOM manipulation
- JavaScript event listeners
- HTML5 Drag and Drop API
- Handling drag events
- Moving elements dynamically
- CSS layouts and styling
- Interactive web development
